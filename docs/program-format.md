# Формат программ тренировок

Источник: xlsx, первый лист, 3 колонки, заголовок в первой строке.

| A: упражнения | B: интенсивность | C: подходы х повторения |
|---|---|---|
| `неделя 1` | | |
| `понедельник` | | |
| сгибания с гантелями на бицепс с супинацией | тяжёлая | 6х8-12 |
| жим гантелей сидя | тяжёлая | дропсет 3х 12-6-6 |

- Строка только с колонкой A: маркер. `неделя N` открывает неделю, день недели (`понедельник`…`воскресенье`) открывает тренировочный день.
- Интенсивность: `тяжёлая`/`тяжелая` → `heavy`, `средняя` → `medium`, `лёгкая` → `light`.
- Предписание: `NхA-B` = N рабочих подходов по A..B повторений; `дропсет Nх A-B-C` = N дропсетов, в каждом A повторений и снижения веса на B, C повторений. Буква «х» может быть кириллической или латинской.
- Опечатки исправляются при импорте (`NAME_FIXES` в `bot/src/gymbot/importers/xlsx_program.py`), например «тяжа» → «тяга».

Конвертация: `PYTHONPATH=bot/src python -m gymbot.importers.xlsx_program in.xlsx data/programs/out.json --name "..."`.
JSON повторяет датаклассы `Program → weeks → days → exercises → prescription`.

## Первая программа: `data/programs/arms_specialization_8w.json`

«Муж, высокий, специализация на руки, 3 дня, дропсеты». 8 недель, Пн/Ср/Пт, 128 позиций, 18 уникальных упражнений.
- Пн и Пт: руки и плечи (бицепс гантели/EZ, французский жим, жимы на плечи, отведения на среднюю/заднюю дельту).
- Ср: базовая (жим лёжа, тяга блока, присед, румынская тяга); с 3-й по 5-ю неделю вариации (жим 30°, горизонтальная тяга, гакк-присед).
- Волнообразная периодизация: нечётные недели тяжёлые для рук (6–7 подходов и дропсеты) при средней базе, чётные наоборот. Объём растёт с 3–6 до 5–7 подходов к 5–7 неделе, 8-я неделя без дропсетов.
