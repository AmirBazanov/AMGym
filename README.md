# GymAPP

Личный дневник тренировок и питания в Telegram: пишешь боту «жим 3 по 10 на 60», нейросеть разбирает, ты подтверждаешь кнопкой. Мини-апп открывает тренировку дня по программе, хранит историю и рисует прогресс.

## Запуск на своём компьютере

Нужно один раз установить:
- [uv](https://docs.astral.sh/uv/getting-started/installation/) (ставит нужный Python сам),
- Node.js 20+,
- `cloudflared` — бесплатный HTTPS-туннель, без него Telegram не откроет мини-апп:
  - Windows: `winget install Cloudflare.cloudflared`
  - macOS: `brew install cloudflared`
  - Linux / WSL: `curl -L -o cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb && sudo dpkg -i cloudflared.deb`

Затем:
```bash
git clone https://github.com/AmirBazanov/AMGym.git && cd AMGym
cp .env.example .env          # впиши BOT_TOKEN и GROQ_API_KEY (или STT_API_KEY, или OPENROUTER_API_KEY для резерва)
uv run --project bot python -m gymbot.dev
```
Команда собирает мини-апп, поднимает туннель, применяет миграции БД, загружает программы из `data/programs/` и запускает бота. В Telegram открой бота, нажми /start, потом кнопку «Дневник» слева от поля ввода. Пока терминал открыт, всё работает; адрес туннеля меняется при каждом запуске, бот обновляет кнопку сам.

Данные лежат в `data/gym.db` (SQLite). Бэкап — просто копия файла.

## Боту можно писать
- **Тренировки** текстом: «жим лёжа 3 по 10 на 60», «сгибания 3х12 по 14, французский жим 3 по 10 на 25», «дропсет на бицепс 12-6-6 с 16 кг» → нейросеть разбирает, ты подтверждаешь кнопкой. Голосовые до 2 минут; если распознано неправильно, исправь словом.
- **Еду**: «200 г гречки и 2 яйца», «три куриные самсы», «плов, касушка и пол лепёшки» → оценка КБЖУ и подтверждение. Модель может уточнить: «Уточни: …» (например, размер или качество).
- **Самочувствие**: «спал 6 часов, болит левое плечо, сил мало» → запись энергии, настроения, боли и сна за один раз. Каждая следующая запись о самочувствии исправляет предыдущую (полная состояние, не добавление). Если это тренировочный день, сразу после сохранения бот отправит обновлённый план дня (если он отличается от программы).
- **Запомни**: «запомни: не ем творог», «запомни, что манты у нас ~90 г» → факты о себе, используются в разборе и советах. Максимум 50 фактов, по 200 символов каждый. Удалить: /facts.
- **/facts** — что бот помнит о тебе; добавлять можно «запомни: …» в чат.
- **/advice** (или просто «что посоветуешь?») — советы по питанию, тренировкам и восстановлению на основе твоих данных, программы и профиля.
- **/plan** — план дня по программе, адаптированный к самочувствию, питанию и восстановлению (см. ниже).
- **/today** — план на сегодня по программе.
- **/undo** — отменить последнюю запись из чата.

## Напоминания
В мини-аппе, вкладка Питание → Напоминания:
- **text**: свой текст, каждый день или в конкретный день недели (Пн–Вс).
- **nutrition**: сводка КБЖУ на сегодня («Добей КБЖУ: осталось 760 ккал / 48 г белка»), или закрыт, или не задана норма.
- **advice**: советы от ИИ, учитывает профиль и блок «О себе»; по умолчанию по воскресеньям.
- **checkin**: бот утром спросит про сон, боли и энергию (ответ сохранится в самочувствие).

## Профиль в мини-аппе
Вкладка Питание → О себе: вес, рост, год рождения, цель (набор массы / сушка / сила / здоровье) и свободный текст про травмы, сон, ограничения (до 500 символов). Используется в советах от ИИ.

## Полезное
- **Маршруты LLM**: бот пробует по очереди Groq (если `GROQ_API_KEY` или `STT_API_KEY` с Groq), потом OpenRouter (если `OPENROUTER_API_KEY`). На 429 маршрут пропускается на 60 с. На других ошибках (400, 401 и т.п.) переходит к следующему. Если вдруг все модели перестали отвечать, выбери текущие бесплатные на https://openrouter.ai/models?max_price=0 и впиши в `OPENROUTER_MODEL` и `OPENROUTER_FALLBACK_MODELS`.
- **Голосовые сообщения**: получи ключ на https://console.groq.com/keys (бесплатный), впиши в `STT_API_KEY`. Голос идёт в Groq для распознавания. Макс. 2 минуты. Если `STT_BASE_URL` содержит `groq.com` и нет отдельного `GROQ_API_KEY`, один ключ используется и для разбора текста. Без ключа бот ответит «Голос не настроен: нужен ключ распознавания в .env.»
- **Проверить разбор**: `uv run --project bot python -m gymbot.llm.check "три куриные самсы"` (или диалог: `--dialog "текст1" "текст2"`, или факты: `--fact "самса ~150 г"`). Выводит маршруты, json_mode и статус каждого запроса.
- **Только мини-апп в браузере**: в `.env` поставь `RUN_BOT=false` и `DEV_USER_ID=1`, запусти `uv run --project bot python -m gymbot.main` и открой http://localhost:8000. Не включай `DEV_USER_ID` вместе с туннелем.
- **Закрыть бота от чужих**: впиши свой Telegram id (бот покажет его на /start) в `ALLOWED_USER_IDS=[...]`.
- **Проверки перед коммитом**: `cd bot && uv run ruff check src tests && uv run pytest -q`; `cd miniapp && npm run typecheck && npm run build`.
