# GymAPP

Личный дневник тренировок и питания в Telegram: пишешь боту «жим 3 по 10 на 60», нейросеть записывает, мини-апп показывает программы и прогресс.

Быстрый старт: скопируй `.env.example` в `.env`, заполни `BOT_TOKEN` и `OPENROUTER_API_KEY`, затем см. `.claude/skills/run-bot/SKILL.md`.
Устройство проекта и правила: `CLAUDE.md`. План: `ROADMAP.md`.
