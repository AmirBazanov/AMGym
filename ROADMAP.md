# ROADMAP

## Этап 0. Фундамент (готово)
- Структура проекта, агенты, скиллы, CLAUDE.md.
- Модели БД для журнала, программ и питания.
- Импорт программы из xlsx → `data/programs/arms_specialization_8w.json` (8 недель, 128 позиций), тесты.
- Каркас бота (`/start`, разбор текста через OpenRouter с предпросмотром) и мини-аппа.

## Этап 1. MVP: бот записывает тренировки и показывает прогресс
- Готово (2026-10-06): миграция 0001, импорт программ из JSON при старте, текст → предпросмотр → «Сохранить», `/today`, `/undo`, кнопка «Дневник», запуск одной командой (`python -m gymbot.dev`).
- Alembic: первая миграция, справочник упражнений из импортированной программы (с алиасами).
- Свободный текст → предпросмотр → кнопки «Сохранить / Исправить» → запись `Workout/WorkoutSet`.
- Ограничение доступа по `ALLOWED_USER_IDS`.
- `/today` — тренировка дня по активной программе; `/program` — выбрать программу и дату старта.
- `/progress <упражнение> [период]` — максимальный вес, расчётный 1ПМ, тоннаж за неделю/месяц; картинка графика.
- `/undo` — удалить последнюю запись.
- Деплой: long polling на VPS или домашнем ПК, SQLite с бэкапом файла.
